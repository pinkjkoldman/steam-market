# 项目简报

> 项目启动时填写，写入 docs/project-brief.md，作为需求阶段的输入。

- 项目名称/代号：**Steam 行情终端（Steam Market Terminal）**
- 项目目标与成功指标：
  - 目标：开发一款类似证券行情软件的个人小工具，用于统计/查看 Steam 市场及可扩展的其他数据源（价格、销量、历史走势等）。
  - 成功指标（待需求阶段细化为可测指标）：
    1. 能稳定拉取并展示 Steam 社区市场指定物品的实时价格、成交量；
    2. 支持历史价格走势图（含 K 线/折线等形态，待确认）；
    3. 支持自选/关注列表与价格提醒；
    4. 数据断网/接口异常时能降级展示缓存数据。
  - **v2（CR-001）目标**：升级为炒股软件风格——分时/日K/均线/盘口/排行榜，补充销量、成交额等数据，内置 Steam 交易规则库与费用计算器。
- 目标用户与核心场景：
  - 目标用户：Steam 饰品/游戏物品交易玩家（个人使用为主）。
  - 核心场景：日常查看饰品行情 → 关注涨跌 → 设置价格提醒 → 辅助决策买卖时机。
- 范围（已知功能要点，待确认优先级）：
  - Steam 社区市场数据拉取（价格、销量、历史记录，接口合规性待评估）；
  - 行情列表与详情（当前价、涨跌幅、历史曲线）；
  - 自选/关注列表（本地保存）；
  - 价格提醒（阈值/涨跌提醒）；
  - 其他数据源扩展（如 BUFF/C5/悠悠有品等第三方平台比价，或用户库存估值，待确认）。
- 约束（技术栈、部署环境、预算、时间、合规）：
  - 技术栈：**Windows 桌面应用，Qt（C++/Qt 6.11 + MinGW，用户已确认）**。
  - 部署环境：本地单机运行（默认假设），无需云服务器。
  - 预算：无额外预算（默认假设），使用免费公开数据接口。
  - 合规：仅限个人学习/自用，遵守 Steam 服务条款与数据使用限制；不涉及账号密码等敏感数据（待安全设计确认）。
- 已知风险与假设：
  - Steam 公开接口无官方 SLA，可能限流、改版或变更（高风险，需缓存与容错设计）；
  - 历史数据回填依赖第三方数据源或自建本地历史库（需确认）；
  - 第三方平台（BUFF 等）接口非公开，可能涉及反爬合规风险（默认范围外，待确认）。
- 决策人/审批人：用户本人
- 交付物目录：docs/（requirements/、design/、implementation/、test/、deploy/、approvals/）
- 流程规模：**小型，用户已确认简化流程**（合并阶段 1+2、阶段 3+4，门禁简化为合并确认）
