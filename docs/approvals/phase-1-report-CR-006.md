## 关键决策

1. 真实历史仅按用户主动打开的单个物品获取，不做全市场逐项历史抓取；原因是限流、会话与条款风险。
2. Steam 历史点、最近 24 小时筛选和本地日 K 聚合必须按实际粒度命名，不宣称逐笔或逐分钟。
3. fixture 继续保留给临时冒烟数据库，但普通运行必须零演示行情；原因是自动测试与产品可信度需要同时满足。
4. 真实联网验收必须由用户通过 Steam 官方页面主动登录；程序和报告不得接触密码、Cookie 或 Steam Guard 密钥。
