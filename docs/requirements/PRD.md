# Steam 行情终端 PRD（产品需求文档）

> 阶段 1 需求分析交付物（与阶段 2 合并门禁）。版本：v1.0（已批准）+ v2 迭代（CR-001，待复审）

## 1. 背景与目标

**背景**：Steam 社区市场（Community Market）是玩家买卖饰品/道具的主要渠道，但官方网页缺少集中行情视图、历史走势、价格提醒与多平台比价能力。本产品参照证券行情软件的交互范式，提供一款单机桌面行情终端。

**目标**：用 Qt 构建 Windows 桌面应用，集中呈现 Steam 市场行情（价格/销量/历史走势），并支持自选关注、价格提醒、持仓估值与第三方平台比价。

**成功指标（可测）**：

| 编号 | 指标 | 度量口径 |
| --- | --- | --- |
| S1 | 行情准确性 | 搜索任意市场物品，展示的当前价/销量与官方页面数据偏差不超过 15 分钟内的正常波动 |
| S2 | 走势图可用 | 详情页可绘制接口返回的全部历史数据点（价格折线 + 销量柱） |
| S3 | 自选刷新 | 自选列表在启动与每个刷新周期后展示最新价与涨跌幅，数据正确 |
| S4 | 提醒时效 | 阈值被最新价命中后 60 秒内触发托盘通知，且同一触发点不重复通知 |
| S5 | 估值正确 | 总市值 = Σ（数量 × 最新市价）；手动改价后重新计算正确 |
| S6 | 离线降级 | 断网或接口失败时，行情/详情展示缓存数据并标注"离线/过期" |

## 2. 目标用户与核心场景

- **画像 1 · 倒卖/交易玩家**：频繁查价，关注热门物品涨跌，设置低价提醒等待买入时机。
- **画像 2 · 收藏/库存玩家**：统计库存总价值与浮动盈亏，观察整体涨跌。

**核心场景**：搜索饰品 → 查看当前价与历史走势 → 加入自选 → 设置提醒 → 后台定时刷新 → 命中阈值时托盘通知 → 回到前台查看详情。

## 3. 功能清单与优先级（MoSCoW）

### Must（第一版必须有）

| 编号 | 功能 | 说明 |
| --- | --- | --- |
| F1 | 市场搜索与行情列表 | 按关键词搜索 Steam 市场物品，展示缩略图、名称、当前价、销量、涨跌幅 |
| F2 | 价格历史走势图 | 详情页折线图（价格）+ 柱状图（销量），数据来自 Steam pricehistory 接口与本地积累 |
| F3 | 自选/关注列表 | 增删物品、持久化、自动刷新最新价与涨跌幅 |
| F4 | 价格提醒 | 低于/高于阈值、24h 涨跌幅超限提醒；托盘通知，防重复触发 |
| F5 | 本地缓存与离线降级 | SQLite 持久化行情/历史数据，接口失败时降级展示并提示 |

### Should（推荐纳入 v1）

| 编号 | 功能 | 说明 |
| --- | --- | --- |
| F6 | 持仓估值 | 手动录入物品/数量/成本价，汇总总市值、成本、浮动盈亏 |
| F7 | 设置 | 货币、刷新间隔、涨跌配色（红涨绿跌/绿涨红跌）、通知开关 |
| F8 | 系统托盘与后台刷新 | 关闭主窗驻留托盘，按间隔后台刷新并触发提醒 |

### Could（扩展，v1 提供可插拔骨架）

| 编号 | 功能 | 说明 |
| --- | --- | --- |
| F9 | 第三方平台比价 | BUFF / C5 / 悠悠有品等平台价格对比；数据源适配器接口 + CSV 导入兜底；实时接口受平台合规限制，接入需评估 |

### Won't（v1 明确不做）

- Steam 账号登录、购买/交易行为；
- 云同步、多用户、移动端；
- 自动抓取绕过登录/验证码的"反爬"能力（合规红线）。

## 4. 功能需求详述

功能需求以用户故事 + Given/When/Then 验收标准为准，见 [user-stories.md](user-stories.md)，覆盖 F1–F9。

## 5. 非功能需求

| 类别 | 要求 |
| --- | --- |
| 性能 | 冷启动 ≤ 5 秒；行情刷新不阻塞 UI（网络异步）；5 年历史数据绘图 ≤ 1 秒；定时刷新默认 10 分钟可配置 |
| 可靠性 | 接口失败自动重试最多 2 次（指数退避）；失败降级展示缓存；应用不崩溃 |
| 兼容性 | Windows 10/11 x64；Qt 6.11 + MinGW 64；高 DPI 缩放正常 |
| 安全 | 仅 HTTPS 访问 Steam；SQL 参数化防注入；不保存账号密码；日志脱敏 |
| 合规 | 遵守 Steam 服务条款与数据使用政策；第三方平台数据仅个人使用，不绕过平台登录/验证码 |
| 可维护性 | 分层架构（UI → Service → Data）；统一错误码；交付物文档与代码一致 |

## 6. 范围外与假设

**假设**：
- Steam 公开接口（search/render、priceoverview、pricehistory）在开发与使用期内可用；
- 用户为个人使用，单机单用户；
- 无需云端部署，数据全部本地保存；
- 历史数据以接口返回为准，本地持续积累作为补充。

**范围外**：见"Won't"清单。

## 7. 风险与待决问题

- 风险明细见 [risk-register](../risk-register.md)（R-001 接口不稳定、R-002 第三方合规、R-003 历史回填、R-004 范围蔓延）。
- 新增风险：R-005 Qt Charts 模块随发行包可用性未知；R-006 BUFF 等平台接口非公开。
- 待决问题：无（本阶段不阻塞；第三方比价接入前需用户对合规风险签收）。

# v2 迭代需求（CR-001）

> 变更内容：把产品升级为"炒股软件"风格，补充销量等数据维度，内置 Steam 交易规则。提出人：用户（2026-08-01）。

## 8. v2 目标

1. 行情体验炒股化：分时图、日 K 线（开高低收 + 成交量 + 均线）、买卖盘口、排行榜；
2. 数据维度扩充：销量、成交额、7 天销量、价格区间等；
3. 内置 **Steam 市场交易规则库**（手续费、7 天交易保护、钱包规则、求购机制等）与**费用计算器**；
4. 模拟交易（含手续费）增强"交易软件"体验。

## 9. v2 功能清单（MoSCoW）

### Must

| 编号 | 功能 | 说明 |
| --- | --- | --- |
| V2-F1 | 分时图 + 当日成交量 | 以当日快照/历史数据聚合近似展示（Steam 无官方分时接口） |
| V2-F2 | 日 K 线与均线 | 由价格历史聚合 OHLC + 成交量；MA5/MA10/MA20；区间 1周/1月/3月/1年 |
| V2-F3 | 买卖盘口 | Steam `itemordershistogram` 接口 → 买盘/卖盘分布 + 前 5 档 + 最高买价/最低卖价 |
| V2-F4 | 行情排行榜 | 成交量榜、涨幅榜、跌幅榜（基于本地采集标的池） |
| V2-F5 | 数据维度 | 详情页增加 7 天销量、成交额、区间高低价 |
| V2-F6 | Steam 交易规则库 | 内置规则条目（手续费/冷却/钱包/求购/限制）+ 规则页浏览 |
| V2-F7 | 费用计算器 | 输入价格 → 卖家到手/买家支付/手续费明细（费率可配置） |

### Should

| 编号 | 功能 | 说明 |
| --- | --- | --- |
| V2-F8 | 模拟交易 | 记录模拟买入/卖出（自动计费），持仓按市价估值，合并到持仓页 |
| V2-F9 | 盘口降级 | 盘口接口受限/需登录时，展示本地求购/出售缓存或提示 |

### Won't（v2 明确不做）

- 真实 Steam 交易/上架/购买操作（仅展示与模拟）；
- 接入 Steam 登录、钱包支付；
- 第三方实时比价接入（仍待合规签收）。

## 10. v2 非功能需求补充

| 类别 | 要求 |
| --- | --- |
| 性能 | 日 K 聚合 5 年数据 ≤ 1 秒；盘口请求不阻塞 UI；排行榜本地计算 ≤ 1 秒 |
| 可靠性 | 盘口接口限流/需登录时优雅降级（V2-F9） |
| 数据准确性 | 交易规则条目标注"以 Steam 官方为准"，费率配置化便于修正 |
| 合规 | 规则库仅做知识展示，不诱导规避平台规则 |

# v3 迭代需求（CR-002）

> 变更：①界面字体可读性优化；②修复 Steam 历史数据接口（需登录会话）；③物品按游戏区分（CS2/DOTA2，TF2 预留）；④自动化交易（登录 + 规则引擎）。

## 11. v3 目标与范围

### 已实施（本批次）

| 编号 | 功能 | 说明 |
| --- | --- | --- |
| V3-F1 | 界面可读性优化 | 全局字号/对比度/间距上调，深色主题文字清晰 |
| V3-F2 | 历史数据接口修复 | pricehistory 日期解析加固（英文区域+多格式）；登录会话后拉取完整历史；未登录显示本地积累并提示 |
| V3-F3 | 多游戏支持 | 行情/详情按游戏过滤（CS2=730、DOTA2=570；TF2=440 预留禁用）；设置默认游戏；唯一约束含 appid（迁移 0003） |

### 待批准实施（自动化交易 v1）

| 编号 | 功能 | 说明 |
| --- | --- | --- |
| V3-F4 | Steam 登录会话 | 用户名+密码+Steam Guard；Cookie 用 Windows DPAPI 加密存储；会话供历史/盘口/交易接口使用 |
| V3-F5 | 自动化交易规则 | 规则表单（买入价≤X、成交量≥Y、预算/数量、卖出价≥X、盈利率、风控限额）；规则列表 CRUD |
| V3-F6 | 规则执行引擎 | 周期检查 → 生成订单意图 → 默认人工确认，可切换自动执行 → 通过 Steam 市场接口下单 → 记录订单状态 |
| V3-F7 | 交易风控 | 单日支出上限、最大持仓、下单冷却、防重复下单、紧急停止、审计日志 |

### Won't（v3 明确不做）

- 非 Steam 平台（BUFF 等）自动交易；
- 绕过 Steam Guard / 验证码 / 账号风控的任何行为；
- 修改钱包余额、提现等资金操作。

## 12. v3 非功能需求

- 凭据安全：密码与 Cookie 不明文落盘（DPAPI 加密），日志脱敏；
- 合规：自动化交易可能触及 Steam 订阅协议自动化条款，内置风险提示与使用限额，用户自行承担；
- 可靠性：接口失败重试 + 降级；下单前校验余额与重复性；会话过期自动提示重新登录。
