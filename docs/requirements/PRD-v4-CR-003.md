# v4 库存优先与批量上架助手（CR-003）

## 背景

v3 的“自动化交易”仍要求手工输入 `market_hash_name`，没有直接展示真实库存；当前库存解析、卡牌上下文和批量卖出模型也无法解决大量卡牌逐个搜索、逐个填价的问题。

## 目标与成功指标

1. 登录后默认直接展示可出售库存，不要求用户先搜索物品；
2. 支持 Steam 社区物品库存（`appid=753/contextid=6`），覆盖普通/闪亮卡牌、表情和背景；
3. 资产与描述正确关联、同名物品自动聚合，库存按 `last_assetid` 完整分页；
4. 用户可批量选择、统一或按规则生成建议价，并进入 Steam 官方批量上架页面完成复核；
5. 不实现无人值守下单、自动绕过市场确认或自动接受手机确认。

## 功能清单（MoSCoW）

### Must

| 编号 | 功能 | 说明 |
| --- | --- | --- |
| V4-F1 | 库存自动加载 | Steam 会话可用后加载库存；支持 `753/6`、`730/2`、`570/2`；按 `last_assetid` 分页 |
| V4-F2 | 正确库存解析 | 以 `classid + instanceid` 关联 `assets` 与 `descriptions`，读取名称、图标、标签、`marketable`、`tradable` 与数量 |
| V4-F3 | 库存直接展示 | 默认进入“我的库存”；支持游戏、类型、可出售状态和文本过滤，搜索仅作为筛选而非前置步骤 |
| V4-F4 | 卡牌聚合 | 同一 `market_hash_name` 聚合数量，同时保留每个独立 `assetid`；普通卡与闪卡分开 |
| V4-F5 | 批量定价草稿 | 支持固定买家支付价、最低在售价减一个价格档、最高求购价三种策略；展示手续费、预计到手与异常项 |
| V4-F6 | 批量上架交接 | 对支持的同质物品打开 Steam 官方 `market/multisell` 页面；用户在 Steam 页面复核提交并完成官方确认 |
| V4-F7 | 接口诊断 | 区分会话失效、库存私密、市场限制、429、解析失败和待确认，提供可执行的恢复提示 |
| V4-F8 | 安全登录 | 通过 Steam 官方登录页面建立会话；应用不收集或保存 Steam 密码，不要求粘贴 Cookie |

### Should

| 编号 | 功能 | 说明 |
| --- | --- | --- |
| V4-F9 | 批量选择工具 | 全选可售卡牌、按游戏/套卡选择、排除低于最低到手价、保留每种 N 张 |
| V4-F10 | 草稿与恢复 | 保存本地草稿；失败或重启后可继续，已售/已上架资产自动剔除 |
| V4-F11 | 界面重构 | 顶部账号/同步状态，左侧筛选，中部物品列表，右侧批量定价与汇总，底部任务与错误队列 |

### Could

- V4-F12：按物品类型保存价格规则模板与最低到手价；
- V4-F13：导出库存、建议价和处理结果 CSV。

### Won't

- 无人值守自动买卖、自动循环下单或后台操纵 Steam 市场；
- 绕过 Steam Guard、验证码、手机/邮件确认或市场限制；
- 保存 Steam 密码、恢复码、共享密钥或自动批准确认；
- 依赖未公开 `sellitem/createbuyorder` 端点作为唯一可用路径；
- 第三方交易平台自动交易。

## 非功能需求

| 类别 | 要求 |
| --- | --- |
| 合规 | 交易提交必须由用户在 Steam 官方页面主动完成 |
| 安全 | 密码仅输入 Steam 官方页面；会话系统级加密；日志不得出现 Cookie/令牌 |
| 性能 | 1000 件库存首次渲染不超过 3 秒（不含网络）；筛选不超过 150ms；分页不阻塞 UI |
| 可靠性 | 429 指数退避并停止并发；分页可恢复；资产不得重复进入草稿 |
| 可用性 | 用户无需理解 appid、contextid、assetid 或 market hash name |
| 可测试性 | 用脱敏库存 JSON 固件覆盖关联、分页、卡牌聚合、不可售过滤与异常状态 |

## 核心场景：批量出售 Steam 卡牌

用户通过 Steam 官方页面登录后打开“我的库存”，应用自动加载 `753/6` 并筛选交易卡牌。用户点击“选择全部可售卡牌”，选择最低在售价减一档或固定价规则，预览每种卡牌数量、买家支付、手续费与预计到手；确认草稿后进入 Steam 官方批量上架页面复核提交，最后在 Steam 手机应用或邮件中完成官方确认。

## 依据与限制

- Steam 用户协议限制脚本、机器人、宏等非人工控制系统：<https://store.steampowered.com/subscriber_agreement/english>
- Steam 官方支持说明市场上架确认无法关闭：<https://help.steampowered.com/en/faqs/view/2E6E-A02C-5581-8904>
- Steam 官方市场 Web API 对普通桌面客户端不可用，受限接口要求发布商密钥：<https://partner.steamgames.com/doc/webapi/ieconmarketservice>
