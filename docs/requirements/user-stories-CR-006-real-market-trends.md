# CR-006 用户故事与验收标准

## US-45 绘制真实 Steam 历史走势（Must）

作为行情用户，我希望打开单个物品时看到 Steam 官方市场历史走势，以便判断价格方向。

- Given 用户已登录且 Steam 返回至少 2 个有效历史点，When 打开物品详情，Then 价格折线按真实时间升序绘制，页面显示来源、币种、采集时间和点数；
- Given 返回点顺序混乱或含重复时间，When 校验并保存，Then 无效点被拒绝、有效点排序且同维度时间幂等；
- Given 只有 1 个有效点，When 渲染，Then 显示该点及“数据不足以形成趋势”，不得补造第二个点；
- Given 普通启动，When 检查行情数据库与曲线，Then 不存在冒烟 fixture 或正弦演示点。

## US-46 登录后恢复历史请求（Must）

作为游客，我希望在历史数据需要登录时就地登录并回到原任务。

- Given 当前无认证会话且历史请求被拒绝，When 错误返回，Then 详情页显示“登录 Steam 获取官方历史”和缓存可用性；
- Given 用户从详情页发起登录并成功，When 身份变为已认证，Then 保留当前物品、周期和页面，并自动重试历史一次；
- Given 登录取消、失败或 WebView2 不可用，When 返回详情页，Then 缓存仍可见且提供手动重试/游客继续；
- Given 会话在请求时失效，When Steam 返回认证错误，Then 全局会话标为过期且不无限重试。

## US-47 区分在线、缓存、空数据与失败（Must）

作为用户，我希望知道曲线是否新鲜可信。

- Given 本次响应通过校验，When 曲线显示，Then 状态为“Steam 在线数据”并显示本次查询时间；
- Given 网络失败且存在缓存，When 详情加载，Then 保留缓存曲线，标明缓存和最后采集时间，不显示“数据已更新”；
- Given Steam 明确成功但没有有效历史点，When 详情加载，Then 显示“Steam 暂无历史点”；
- Given HTTP 错误、Steam `success=false`、JSON/字段变化或时间/价格非法，When 解析，Then 显示对应错误和恢复动作，且不得作为成功空数据写入；
- Given 返回 429/403，When 请求结束，Then 不高频自动重试，并明确提示稍后重试。

## US-48 可靠的价格与成交量图表（Must）

作为用户，我希望时间、价格和成交量对齐，避免读错走势。

- Given 有多个历史点，When 绘图，Then 价格点使用连续时间轴，成交量与同一时间点对齐并使用独立量轴/子图；
- Given 时间跨度为 7 天、30 天、90 天、1 年或全部，When 切换周期，Then 只筛选已加载真实点且坐标范围重新计算；
- Given 数据存在长时间断档，When 渲染，Then 不用虚构点填平断档，并以状态文字说明；
- Given 用户悬停数据点，When 显示提示，Then 包含本地时间、价格、成交量和数据来源；
- Given 使用 1040×680 或 150% DPI，When 查看图表，Then 坐标标签和状态文字不重叠且可辨认。

## US-49 准确表达最近 24 小时与日 K（Must）

作为用户，我希望图表名称符合数据粒度。

- Given 最近 24 小时只有稀疏历史点，When 查看对应页签，Then 文案为“24h 历史点”或等价准确表达，不宣称逐分钟；
- Given 日 K 由历史点聚合，When 查看说明，Then 明确标注“按 Steam 历史点本地聚合”；
- Given 某日只有一个点，When 生成日 K，Then O/H/L/C 可相同并标为稀疏数据，不补造波动；
- Given 统计 7 天销量/成交额，When 计算，Then 只使用有效历史点并显示其数据口径。

## US-50 手动刷新与限流恢复（Should）

作为用户，我希望可控制刷新且不会触发 Steam 限流。

- Given 详情已加载，When 点击刷新，Then 按既定限速发起一次请求并显示加载状态；
- Given 请求进行中，When 再次点击刷新，Then 不创建并发重复请求；
- Given 收到 429，When 查看页面，Then 刷新动作暂时禁用或提示稍后重试；
- Given 同一数据刚刚成功加载，When 切换图表周期，Then 不重复请求远端历史。

## US-51 真实联网验收可追溯（Must）

作为发布验收人，我希望确认正式程序确实绘制真实 Steam 数据。

- Given 用户在应用内通过 Steam 官方页面主动登录，When 打开约定测试物品，Then 能看到至少 2 个真实历史点、来源、币种与采集时间；
- Given 完成联网验收，When 查看测试报告，Then 记录 appid、market_hash_name、点数、首末时间、结果和脱敏截图，不记录 Cookie/令牌；
- Given 网络或 Steam 限流导致无法完成，When 结束测试，Then 报告为外部阻塞，不使用 fixture 冒充通过；
- Given 登出，When 再次访问详情，Then 网络 Cookie 被清理，已有缓存按缓存状态显示。
