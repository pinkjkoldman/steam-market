# CR-005：市场概览改为 Steam 全市场数据

- 提出人：用户
- 日期：2026-08-13
- 状态：G2 设计修订，待重新审批
- 影响阶段：G1 范围补充、G2 架构/API/数据/UI/安全，G3 实现，G4 联网与降级验证

## 1. 变更内容

市场概览和物品浏览不再以本地关注/浏览标的池作为市场范围，而以 Steam Community Market 当前可检索的全部市场结果为远端事实源。数据必须来自 Steam 官方域名返回的市场页面数据；本地数据库只作为分页缓存和离线降级。

## 2. 术语

- `Steam 全市场`：当前查询条件下 Steam Community Market 返回的全部可检索结果集合；
- `全市场概览`：Steam 返回的总结果数、重点游戏结果数、热门排序、最低挂单价与当前挂单量；
- `全量镜像`：在本地实际下载全部结果。当前明确不做，除非获得 Valve 许可或合作伙伴接口；
- `Steam 官方市场公开页面数据`：由 `steamcommunity.com/market` 官方网页端点返回，但不是 Steamworks 面向第三方承诺的正式公开 API。

## 3. Must

| 编号 | 需求 | 验收摘要 |
|---|---|---|
| CR5-F1 | 全市场范围 | 概览显示 Steam 当前全站 `total_count`，不使用本地关注数代替 |
| CR5-F2 | 重点游戏分布 | 显示 CS2、Dota 2、TF2、Steam 社区物品的 Steam 返回结果数 |
| CR5-F3 | Steam 热门列表 | 使用 Steam 官方市场热门排序，展示名称、游戏、最低挂单价与当前挂单量 |
| CR5-F4 | 全市场浏览 | 用户可通过远端分页访问当前搜索结果全集，显示 x–y / total_count |
| CR5-F5 | 来源透明 | 显示来源、查询范围、币种、时间及实时/缓存状态 |
| CR5-F6 | 低频与降级 | 429/403/离线/结构变化停止预取，保留缓存和明确错误 |
| CR5-F7 | 深度按需 | 历史、盘口和价格详情只在用户选择物品时加载，不遍历全市场 |
| CR5-F8 | 术语准确 | 不宣称 Valve 正式全市场 API、实时全量镜像或官方全市场 24h 指数 |

## 4. Should

- 重点游戏范围可点击进入对应全市场浏览；
- 缓存热门页和最近访问查询，离线可查看并显示缓存时间；
- 保存有限范围总数快照，用于展示“较上次采集变化”，明确为本地快照比较；
- 提供“打开 Steam 官方市场”恢复入口。

## 5. Won't

- 启动或后台遍历约 52 万结果；
- 对全市场逐个请求 `priceoverview`、`pricehistory` 或盘口；
- 使用 Steam 登录 Cookie 做无人值守全量采集；
- 绕过 429、验证码、访问控制或轮换代理；
- 将发行商 publisher key 嵌入桌面程序；
- 未获 Valve 许可时建设持续全量市场镜像。

## 6. 验收标准

### US-42 Steam 全市场概览

- Given Steam 官方市场端点可用，When 打开市场概览，Then 显示全站及重点游戏 `total_count`、热门物品、Steam 来源、币种与查询时间；
- Given 用户点击某游戏，When 切换范围，Then 热门列表和总数来自对应 appid 的 Steam 响应；
- Given Steam 响应不含全市场 24h 涨跌，When 渲染首页，Then 不显示伪造的今日上涨/下跌卡。

### US-43 全市场物品浏览

- Given 全站范围，When 翻页，Then 客户端以 Steam `start/pagesize` 请求对应远端页并显示 `x–y / total_count`；
- Given 查询或筛选改变，When 旧响应晚到，Then 不覆盖当前结果；
- Given 返回详情，When 恢复浏览页，Then 查询、范围、页码和选中项保持。

### US-44 限流、缓存与范围透明

- Given Steam 返回 429，When 请求失败，Then 停止预取、按 Retry-After/退避等待并允许浏览缓存；
- Given 离线且存在缓存，When 打开页面，Then 显示缓存内容与采集时间，不标为实时；
- Given 无缓存或字段结构变化，When 无法解析，Then 显示恢复说明与官方市场链接，不展示旧数字为最新；
- Given 用户查看数据说明，Then 明确这是 Steam 官方市场公开页面数据而非 Valve 正式第三方全市场 API。

## 7. 成功指标

- 正常网络下市场概览可在缓存首屏 <300 ms、远端更新目标 <5 s 内可用；
- 用户无需先关注物品即可看到 Steam 全市场范围和热门结果；
- 任何市场总数都能追溯到某次 Steam 响应；
- 不发生启动全量抓取，不因翻页形成并发突发；
- 所有限流与缓存状态对用户可见。

## 8. 风险接受

用户要求产品呈现 Steam 全市场范围；项目采用“远端全集可访问 + 按需分页缓存”满足目标。由于网页端点不是正式公开 API且 Steam 条款限制自动化，全量镜像不进入当前批准范围，正式发布前需要再次合规复核。
