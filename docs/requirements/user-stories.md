# 用户故事与验收标准

> 覆盖功能 F1–F9。验收标准采用 Given/When/Then，是设计、开发、测试的共同基线。

## US-01 市场搜索与行情列表（F1 · Must）

作为饰品交易玩家，我希望输入关键词即可搜索 Steam 市场物品并查看当前价与销量，以便快速比价和选品。

**验收标准**：
- Given 应用已联网且 Steam 接口可用，When 我输入关键词（如 "AK-47 | Redline"）并搜索，Then 列表展示匹配物品的缩略图、名称、当前价、销量（销量缺失时显示"—"）。
- Given 搜索无结果，When 我提交搜索，Then 展示"无匹配物品"空态与重试/清空入口。
- Given 接口请求失败，When 我提交搜索，Then 展示统一错误提示且应用不崩溃，可重试。

## US-02 价格历史走势图（F2 · Must）

作为交易玩家，我希望查看物品历史价格与销量走势，以便判断买卖时机。

**验收标准**：
- Given 我打开某物品详情页且接口可用，When 页面加载完成，Then 展示价格折线图与销量柱状图，并标注最新价与数据时间。
- Given 本地已有历史缓存，When 接口不可用，Then 用缓存绘图并显示"数据可能过期"提示。
- Given 数据点少于 2 个，When 页面加载，Then 展示"历史数据不足"空态。

## US-03 自选/关注列表（F3 · Must）

作为玩家，我希望把关注的物品加入自选列表并自动刷新，以便集中跟踪涨跌。

**验收标准**：
- Given 我在物品详情页，When 点击"加入自选"，Then 该物品出现在自选列表且重启后仍存在。
- Given 自选列表非空，When 应用启动或到达刷新间隔，Then 自动拉取最新价与涨跌幅并更新列表。
- Given 我在自选列表，When 执行移除操作（按钮/右键菜单），Then 物品被移除且持久化。
- Given 某自选物品数据拉取失败，When 列表刷新，Then 该行保留上次数据并标记"更新失败"。

## US-04 价格提醒（F4 · Must）

作为玩家，我希望在价格达到阈值时收到通知，以便不错过买卖时机。

**验收标准**：
- Given 我在详情页或自选页，When 设置提醒（低于 X / 高于 X / 24h 涨跌幅超过 Y%），Then 提醒保存并出现在提醒列表，含启用开关。
- Given 提醒启用且最新价命中条件，When 后台刷新完成，Then 60 秒内弹出托盘通知并标记已触发，同一数据点不重复通知。
- Given 提醒被禁用，When 刷新，Then 不触发通知。
- Given 阈值输入非法（≤0 或非数字），When 保存，Then 提示校验错误且不保存。

## US-05 持仓估值（F6 · Should）

作为收藏玩家，我希望记录库存并按市价估算价值，以便了解资产变动。

**验收标准**：
- Given 我在持仓页，When 添加物品（名称/数量/可选成本价），Then 按最新市价计算该行市值与盈亏。
- Given 持仓非空，When 页面加载或刷新完成，Then 汇总展示总市值、总成本、浮动盈亏与盈亏率。
- Given 某物品无市价数据，When 计算汇总，Then 该行市值显示"—"，汇总中排除该行并提示数据缺失。

## US-06 第三方平台比价（F9 · Could）

作为玩家，我希望对比 Steam 与第三方平台价格，以便找到更优渠道。

**验收标准**：
- Given 已启用至少一个数据源且平台存在该物品，When 打开详情页比价区，Then 展示各平台价格、币种与更新时间。
- Given 某平台无数据或不可用，When 展示比价区，Then 该平台显示"无数据"且不影响其他平台。
- Given 未配置任何数据源，When 打开比价区，Then 提示配置方式或 CSV 导入入口。

## US-07 本地缓存与离线降级（F5 · Must）

作为用户，我希望断网或接口异常时仍能看到最近数据，以便持续跟踪。

**验收标准**：
- Given 应用曾成功拉取数据，When 断网或接口失败，Then 行情/详情页展示缓存数据并标注"离线/数据过期"。
- Given 缓存为空且无网络，When 打开页面，Then 展示空态与"重试"按钮。

## US-08 设置（F7 · Should）

作为用户，我希望自定义货币、刷新频率与配色，以便符合个人习惯。

**验收标准**：
- Given 我打开设置页，When 修改货币/刷新间隔/涨跌配色/通知开关并保存，Then 设置立即生效并持久化。
- Given 刷新间隔非法（如 0 或负数），When 保存，Then 提示校验错误且不落库。

## US-09 系统托盘与后台刷新（F8 · Should）

作为用户，我希望应用最小化后仍在后台刷新，以便持续接收提醒。

**验收标准**：
- Given 应用运行中，When 我最小化或关闭主窗口，Then 应用驻留系统托盘并继续按间隔刷新。
- Given 提醒被触发，When 应用在后台，Then 通过托盘气泡展示物品名与价格。

# v2 用户故事（CR-001）

## US-10 分时图与当日成交量（V2-F1 · Must）

作为玩家，我希望看到物品当日价格走势与成交量，以便判断日内波动。

**验收标准**：
- Given 我打开详情页并切换到"分时"标签，When 存在当日快照/历史数据，Then 展示当日价格曲线与成交量柱（数据点≥2 时绘制，否则提示数据不足）。

## US-11 日 K 线与均线（V2-F2 · Must）

作为玩家，我希望查看日 K（开高低收 + 成交量）与均线，以便识别趋势。

**验收标准**：
- Given 详情页存在历史数据，When 切换到"日K"标签，Then 展示 OHLC 蜡烛图 + 成交量柱 + MA5/MA10/MA20 均线，且区间切换（1周/1月/3月/1年）生效。
- Given 历史数据不足 2 天，When 绘制 K 线，Then 展示"K线数据不足"空态。

## US-12 买卖盘口（V2-F3 · Must）

作为玩家，我希望看到当前买盘/卖盘分布与五档挂单，以便判断流动性。

**验收标准**：
- Given 盘口接口可用，When 打开详情页盘口区，Then 展示买盘/卖盘分布图、最高买价、最低卖价与前 5 档挂单。
- Given 盘口接口受限或失败，When 刷新盘口，Then 展示缓存或"盘口暂不可用"提示，不影响页面其他功能。

## US-13 行情排行榜（V2-F4 · Must）

作为玩家，我希望看到成交量/涨幅/跌幅榜，以便发现热门标的。

**验收标准**：
- Given 本地有足够快照数据，When 打开排行榜页并选择榜单类型，Then 展示 Top N 列表（名称、价格、指标值）并可进入详情。
- Given 数据不足，When 打开排行榜，Then 展示"数据积累中"提示与采集说明。

## US-14 销量与成交额等数据（V2-F5 · Must）

作为玩家，我希望详情页展示 7 天销量、成交额与区间高低价。

**验收标准**：
- Given 详情页有历史数据，When 页面加载，Then 展示 7 天销量合计、近 N 日成交额、统计区间最高/最低价。

## US-15 Steam 交易规则库（V2-F6 · Must）

作为玩家，我希望在应用内查阅 Steam 市场交易规则。

**验收标准**：
- Given 我打开"交易规则"页，When 浏览，Then 按分类展示规则条目（手续费、交易保护、钱包、求购、限制等），每条标注来源与更新时间。

## US-16 费用计算器（V2-F7 · Must）

作为玩家，我希望计算挂单实际到手/实际支付。

**验收标准**：
- Given 我在费用计算器输入价格与方向（卖/买），When 计算，Then 展示买家支付、卖家到手、Steam 费与游戏费明细（费率默认 CS2：5% + 10%，可在设置调整）。

## US-17 模拟交易（V2-F8 · Should）

作为玩家，我希望记录模拟买卖并看到含手续费盈亏，以便复盘策略。

**验收标准**：
- Given 持仓页选择"模拟交易"，When 录入买入/卖出（数量、价格），Then 自动计算手续费与合计，并更新持仓市值/盈亏。
- Given 卖出数量超过持仓，When 提交，Then 校验拒绝并提示。

# v3 用户故事（CR-002）

## US-18 游戏切换（V3-F3 · Must）

作为玩家，我希望按游戏查看行情，CS2 与 DOTA2 数据互不混淆。

**验收标准**：
- Given 我在行情页选择游戏（CS2/DOTA2），When 搜索物品，Then 结果仅来自该游戏且列表标注游戏；
- Given 在设置中选择默认游戏，When 重启应用，Then 行情页默认选中该游戏；
- Given 军团要塞2选项，When 查看，Then 显示为"预留"不可用。

## US-19 Steam 登录会话（V3-F4 · Must）

作为用户，我希望登录 Steam 账户以便获取完整历史与盘口数据。

**验收标准**：
- Given 账户页输入用户名/密码，When 提交，Then 弹出 Steam Guard 验证码输入框并登录；
- Given 登录成功，When 请求价格历史/盘口，Then 使用会话 Cookie 拉取成功；
- Given 关闭应用，When 再次启动，Then 会话凭据加密保存，可选择自动恢复或重新登录；
- Given 会话失效，When 请求数据，Then 提示重新登录且不崩溃。

## US-20 自动化交易规则（V3-F5 · Must）

作为用户，我希望录入交易规则让应用自动判断买卖时机。

**验收标准**：
- Given 规则页，When 新建规则（游戏/物品/方向/价格阈值/数量/预算/风控），Then 规则保存并可在列表启停；
- Given 规则存在且当前价满足条件，When 刷新周期到达，Then 生成订单意图并提示确认（默认人工确认模式）。

## US-21 订单执行与记录（V3-F6 · Must）

作为用户，我希望确认或自动执行订单并跟踪状态。

**验收标准**：
- Given 人工确认模式，When 意图生成，Then 弹出订单详情等待确认；
- Given 自动执行已开启，When 条件满足，Then 调用 Steam 市场接口下单并写入订单记录；
- Given 订单已提交，When 查看订单页，Then 展示状态（待执行/成功/失败/已取消）与错误原因。

## US-22 交易风控（V3-F7 · Must）

作为用户，我希望自动化交易不会失控。

**验收标准**：
- Given 设置单日支出上限，When 当日累计超限，Then 停止产生新订单并提示；
- Given 同一物品规则已在短时间触发，When 再次检查，Then 冷却期内不重复下单；
- Given 任意时刻，When 点击"紧急停止"，Then 立即停止检查与下单。

## US-23 历史数据降级（V3-F2 · Must）

作为未登录用户，我希望应用仍可用且提示原因。

**验收标准**：
- Given 未登录，When 请求历史/盘口，Then 展示本地积累数据并提示"登录 Steam 可获取完整历史"；
- Given 已登录，When 请求历史，Then 历史数据正常拉取并缓存。
