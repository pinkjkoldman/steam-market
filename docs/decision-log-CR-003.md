# 决策日志附录：CR-003

## D-012：改为库存优先的批量上架助手（待审批）

- 日期/阶段：2026-08-03 / v4 需求变更
- 决策者：总设计师建议，待用户批准
- 背景：用户核心场景是大量卡牌逐个搜索、逐个填价；现有 v3 仍需手填名称，库存解析和批量卖出模型无法覆盖；Steam 当前用户协议限制非人工自动化，市场上架还要求不可关闭的官方确认
- 备选方案：继续调用未公开 `sellitem/createbuyorder` 做无人值守交易；仅保留行情；使用 Steam 官方页面完成批量交接
- 建议结论：自动加载并聚合库存、生成批量定价草稿，再交接 Steam 官方 `market/multisell` 页面由用户复核提交；移除无人值守自动执行承诺
- 理由：解决“不搜索、不逐个点击”的主要痛点，同时避免把不稳定内部端点和账号风险包装成可靠能力
- 影响：需求、认证、库存模型、API 适配、TradingPage、测试和发布均需重做；v3 G5 暂停
