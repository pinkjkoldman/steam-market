## 项目总结（收尾）

### 交付概况

- v1.0.0：行情/走势/自选/提醒/持仓/比价/缓存；G1~G4 获批，制品交付；
- v2.0.0（CR-001）：分时/日K+均线/盘口/排行榜/数据维度/交易规则库/费用计算器/模拟交易；全部门禁通过；
- 最终制品：release/SteamMarketTerminal-portable.zip（25.8 MB）、SteamMarketTerminal-Setup.exe（18.3 MB）；
- 单元测试 37/37 通过，冒烟退出码 0，打包版干净环境验证通过。

### 关键决策回顾

1. Qt Widgets 单进程 + SQLite + Qt Charts（ADR-001/002）；
2. 服务契约 OpenAPI 化，分层单向依赖；
3. Steam 公开接口（search/priceoverview/pricehistory/itemordershistogram）+ 限速/重试/缓存降级；
4. 第三方比价可插拔 + CSV 兜底（合规待签收）；
5. 费用模型按卖家到手价（Steam 5% + 游戏 10%），费率配置化；
6. 简化流程：1+2 合并、3+4 合并，门禁 5 次。

### 经验教训

- 迁移脚本内嵌资源并统一由迁移器标记版本，避免重复插入冲突；
- PowerShell 5.1 对无 BOM UTF-8 脚本按 ANSI 解析，含中文的脚本需纯 ASCII 或带 BOM；
- qmake SUBDIRS 在本机沙箱并发写缓存冲突，改为分目录构建；
- Qt6 移除 QTextStream::setCodec、Charts 类在全局命名空间等 API 差异需实测；
- 沙箱拦截 qmake/windeployqt 子进程写入，构建打包需提权执行。

### 持续事项（非阻塞）

- 真实 Steam 接口（盘口/分时）与托盘通知联网实测；
- 交易规则与费率随 Steam 政策维护（设置页可校准）；
- 第三方实时比价待合规签收后按 IPriceSource 接入。
