# CR-003 G3 决策日志

| 决策 | 结论 | 原因 |
|---|---|---|
| 登录方式 | 嵌入 WebView2 打开 Steam 官方登录页 | 不接触密码并支持 Steam Guard |
| 无登录模式 | 允许公开 SteamID64 只读库存 | 公共库存不必强制登录 |
| 自动化边界 | 自动选择、数量与定价草稿；官方页面人工确认 | 降低误挂单、风控和账号安全风险 |
| 库存刷新 | 分页完成后原子切换 | 避免半份库存覆盖完整快照 |
| 金额 | 整数最小货币单位 | 避免浮点误差 |
| 批量交接 | 40 组/1800 字节双限制拆批 | 控制官方 URL 兼容性 |
| Qt 运行时 | 开发测试注入 PATH，发布使用 windeployqt | 消除 `0xC0000135` 环境依赖 |
| WebView2 Loader | 显式加入发布包 | windeployqt 不负责该第三方 DLL |
