# 发布报告（v2.0.0）

## 发布信息

- 产品：Steam 行情终端（Steam Market Terminal）
- 版本：v2.0.0（CR-001 第二代迭代）
- 发布日期：2026-08-01
- 目标平台：Windows 10/11 x64（Qt 6.11 MinGW，自包含）

## v2 新增能力

- 分时图、日K（蜡烛+成交量+MA5/10/20）、买卖盘口（五档+最优价）、行情排行榜；
- 数据维度扩充：7 天销量、成交额、90 天区间；
- Steam 交易规则库（9 条分类规则）+ 费用计算器（费率可配置）；
- 模拟交易（含手续费与持仓校验）。
