# 监控与回滚方案

## 1. 监控与可观测

| 观测项 | 方式 |
| --- | --- |
| 应用日志 | `%APPDATA%/Personal/SteamMarketTerminal/logs/app.log`（5MB×2 滚动） |
| 数据健康 | 启动时保留策略清理 + 每日 .bak 备份（设置页"立即备份"） |
| 接口状态 | 状态栏"在线/离线/降级" + 缓存 stale 标记 |
| 失败信号 | 网络错误/限流（RATE_LIMITED）统一错误提示，不崩溃 |

## 2. 回滚触发条件

- 新版本无法启动或数据库迁移失败；
- 行情/自选/提醒功能异常且影响日常使用；
- 用户主观不认可新版本行为。

## 3. 回滚步骤

1. 保留旧版目录（`release/SteamMarketTerminal` 即当前有效版本），升级时先复制旧目录为 `SteamMarketTerminal.bak`；
2. 若新版本异常：删除新目录，恢复旧目录，双击旧版 exe 即可；
3. 数据库兼容：迁移采用"只增不改"策略，旧版可读取旧库；如新版已升级 schema 且需回退，用 `steam_market.db.bak` 恢复；
4. 验证：运行 `--smoke-test` 退出码 0 + 手工打开自选/持仓页确认数据正常。

## 4. 说明

- v1 为单机便携部署，无服务器回滚复杂度；任何机器上保留 zip 即可随时重建环境。
