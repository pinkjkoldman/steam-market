# CR-003 前端实现

主导航“自动交易”已替换为“库存助手”。新工作台提供：

- Steam 官方登录与公开 SteamID64 两种入口；
- 直接同步并展示库存，不要求手工搜索 `market_hash_name`；
- Steam 社区物品、CS2、Dota 2、TF2 等 app/context 预设；
- 本地文本过滤、仅交易卡牌、仅可出售过滤；
- 当前可见项全选、逐项数量选择；
- 固定买家支付价、预计手续费和卖家实收汇总；
- 超限自动拆批并依次打开 Steam 官方批量出售页面；
- 未登录、空库存、同步中、失败保留旧快照等状态提示。

界面不提供“跳过确认”“后台自动提交”或账户密码输入框。冒烟截图：`docs/test/smoke-cr003-runtime.png`。
