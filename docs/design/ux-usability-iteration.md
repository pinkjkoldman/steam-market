# 界面可用性迭代（2026-08-13）

## 目标

本轮聚焦高频路径：全局页面切换、行情搜索、列表进入详情、从详情返回来源页。保留现有业务服务、API 与数据模型。

## 新导航规则

1. 左侧导航始终表示一级工作区，详情页不占用一级导航项。
2. 从行情、自选、持仓或排行进入详情时记录来源；返回按钮和 `Esc` 均返回该来源，而非固定回行情。
3. 详情页标题下显示来源与返回提示；点击侧栏任一项立即退出详情。
4. `Alt+1` 至 `Alt+7` 依次打开行情、自选、持仓、排行、规则、库存、设置。
5. 所有程序化跳转与用户点击统一经过 `activatePage()`，同步内容、标题和说明。

## 行情页任务流

- 搜索输入支持清除，Enter 与主按钮均可提交。
- 搜索期间按钮禁用并显示“搜索中”，结果表暂时不可操作，避免重复请求。
- 无结果、错误、成功均显示明确状态；成功后默认选中首行。
- 双击或键盘 Enter 打开当前物品详情。

## 视觉层级

- 深色工作台壳层：品牌区、一级导航、页面标题、内容区、全局状态栏。
- 主操作使用蓝色实心按钮；普通操作使用深色描边；危险操作预留红色语义样式。
- 表格使用 40px 默认行高、整行单选、弱化网格并强化选中态。
- 页面状态采用独立信息条，不与业务内容混排。
