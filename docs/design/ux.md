# 用户流程与信息架构

> UI/UX 设计师交付物（阶段 2）。

## 1. 信息架构

```mermaid
flowchart TB
    APP[Steam 行情终端]
    APP --> NAV[左侧导航栏]
    NAV --> M[行情]
    NAV --> W[自选]
    NAV --> P[持仓]
    NAV --> S[设置]
    M --> MS[搜索+列表]
    MS --> D[物品详情]
    D --> W
    D --> A[设置提醒]
    D --> C[比价区]
    W --> WD[自选行操作：移除/提醒/详情]
    P --> PD[持仓行操作：编辑/删除/刷新]
    S --> SF[货币/刷新间隔/配色/通知]
    TRAY[系统托盘] -->|后台刷新| W
    TRAY -->|命中提醒| NOTIFY[托盘通知]
```

## 2. 主流程

### 2.1 查价与跟踪（US-01/02/03/04）

```mermaid
flowchart LR
    START[启动] --> HOME[行情页]
    HOME -->|搜索| LIST[结果列表]
    LIST -->|点击物品| DETAIL[详情页]
    DETAIL -->|加入自选| WATCH[自选列表]
    DETAIL -->|设置提醒| ALERT[提醒列表]
    DETAIL -->|查看比价| COMPARE[比价区]
```

入口：行情页搜索框；出口：详情页"加入自选/设置提醒/比价"。

### 2.2 估值（US-05）

```mermaid
flowchart LR
    P1[持仓页] -->|添加物品| FORM[物品/数量/成本价]
    FORM --> ROW[持仓行]
    ROW -->|后台刷新市价| VAL[市值/盈亏]
    VAL --> SUM[汇总卡片：总市值/总成本/盈亏率]
```

### 2.3 提醒触达（US-04/09）

```mermaid
flowchart LR
    TIMER[后台刷新] --> CHECK{命中阈值?}
    CHECK -->|是| DEDUP{去重检查}
    DEDUP -->|未触发过| NOTIFY[托盘气泡]
    CHECK -->|否| IDLE[等待下个周期]
```

## 3. 页面层级与状态

| 页面 | 入口 | 关键状态 |
| --- | --- | --- |
| 行情页 | 启动默认 | 加载中 / 有结果 / 空结果 / 接口错误 |
| 详情页 | 点击列表/自选/持仓行 | 加载中 / 正常 / 离线(缓存) / 数据不足 |
| 自选页 | 导航 | 空列表引导 / 正常 / 部分行更新失败 |
| 持仓页 | 导航 | 空列表引导 / 正常 / 部分行无市价 |
| 设置页 | 导航 | 正常 / 校验错误 |
| 托盘 | 常驻 | 正常 / 通知 |
