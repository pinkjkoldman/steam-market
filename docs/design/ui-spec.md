# UI 规范与组件契约

> UI/UX 设计师交付物（阶段 2）。布局为低 fidelity 线框，组件契约供前端（Qt Widgets）直接落地。

## 1. 主窗口布局

```text
+------------------------------------------------------------------+
| 标题栏：Steam 行情终端                       [最小化][托盘][关闭] |
+--------+---------------------------------------------------------+
| 导航栏  |  页面内容区（QStackedWidget）                            |
| 行情    |                                                         |
| 自选    |   当前页面（列表 / 详情 / 表单）                          |
| 持仓    |                                                         |
| 设置    |                                                         |
+--------+---------------------------------------------------------+
| 状态栏：数据源状态 ● 在线/离线 · 上次同步时间 · 币种               |
+------------------------------------------------------------------+
```

- 左侧导航固定宽度 160px；关闭主窗默认驻留托盘（可设置）；
- 状态栏实时反映"在线/离线/降级"与上次同步时间（对应 US-07）。

## 5. 设置页

| 分组 | 控件 |
| --- | --- |
| 行情 | 币种下拉（CNY/USD/EUR/RUB）、刷新间隔（分钟，1–1440） |
| 显示 | 涨跌配色（红涨绿跌 / 绿涨红跌）、走势图区间默认值 |
| 通知 | 启用通知开关、关闭主窗驻留托盘开关 |
| 数据 | 请求间隔（毫秒）、备份数据库按钮、数据目录路径展示 |

## 6. 组件契约（前端实现基线）

| 组件 | 属性/信号 | 状态 | 对应页面 |
| --- | --- | --- | --- |
| SearchBar | `queryChanged(QString)`、`submitted(QString)`；防抖 400ms | 默认/聚焦/加载/错误 | 行情 |
| MarketTable | 列模型 + 排序 + 双击信号 `itemActivated(MarketItem)` | 加载/空/错误/正常 | 行情、自选 |
| PriceChart | `setPoints(PricePoint[])`、区间切换信号；折线+柱状 | 加载/正常/数据不足 | 详情 |
| PriceCard | 展示最新价/涨跌幅/销量，涨跌色由 tokens 控制 | 正常/无数据 | 详情 |
| ComparePanel | 平台行列表 + 刷新；平台不可用显示"无数据" | 正常/部分缺失/未配置 | 详情 |
| AlertDialog | 条件类型单选 + 阈值输入 + 校验 | 默认/校验错误 | 详情、自选 |
| TrayManager | 气泡通知 `showMessage(title, body)`；主窗显隐 | 正常 | 全局 |
| Toast | 非阻塞提示（操作成功/失败） | 正常/错误 | 全局 |
| ConfirmDialog | 危险操作确认（移除自选/删除持仓/删除提醒） | 正常 | 自选、持仓 |

所有列表组件须支持：键盘上下选择、回车触发默认操作、右键菜单（移除/提醒/详情）。

# v3 UI 变更（CR-002）

## 13. 可读性优化（已实施）

- 全局基础字号上调（约 9.8pt / 13px），表格、输入框、按钮、页签同步放大；
- 标题与价格卡片 22px、强调色提亮（#5A93FF），状态栏对比度提升；
- 组件间距/内边距加大，避免挤压。

## 14. 游戏切换（已实施）

- 行情页搜索栏旁"游戏"选择器：CS2 / DOTA2 / 军团要塞2（预留禁用）；
- 设置页"默认游戏"：启动时行情页自动选中。
