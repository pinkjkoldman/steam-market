# CR-004 账户入口与游客模式安全设计（G2）

## 1. 资产与信任边界

资产：Steam 认证 Cookie、SteamID、用户对当前身份的认知、待执行账户动作、本地关注数据。

边界：

- 本地 Qt UI ↔ `SteamSessionService`；
- 服务 ↔ WebView2 官方 Steam 页面；
- Cookie 内存桥 ↔ Steam HTTP 客户端；
- 设置数据库 ↔ 启动控制器。

应用不是 Steam 凭据处理方；用户名、密码与二次验证码只能输入官方 Steam 页面。

## 2. 核心安全不变量

1. `Authenticated` 只能由官方页面完成登录、提取合法会话 Cookie并解析到 SteamID 后产生。
2. 游客、公开 SteamID 或历史缓存均不能提升为已认证。
3. 权限检查在业务命令入口执行，禁用按钮只是一层展示。
4. 重启后初始身份不得为 `Authenticated`。
5. 旧 WebView2 用户数据目录可能含 Cookie，因此每个进程第一次登录导航前必须完成删除。
6. 清理失败时阻断登录导航，允许游客继续；不得以“可能已登录”继续。
7. 日志、设置、数据库、崩溃信息不得包含 Cookie、密码、验证码或完整回跳 URL。

## 3. 威胁模型

| 威胁 | 场景 | 控制 | 验证 |
|---|---|---|---|
| 身份欺骗 | UI 依据 SteamID 非空显示已登录 | 唯一状态源 + 原子快照 | 非法组合单测 |
| 权限提升 | 游客直接调用私有库存命令 | 服务入口调用 AccessGate | 绕过 UI 的集成测试 |
| 残留会话 | WebView2 UDF 跨重启保留 Cookie | 首次登录导航前清 Cookie；退出再清理 | 预置残留 Cookie 测试 |
| 导航劫持 | 登录页跳转至非 Steam 域 | 复用 CR-003 HTTPS 与主机白名单 | 恶意重定向测试 |
| 凭据窃取 | 应用内伪造登录表单 | UI 禁止凭据控件，官方 WebView 唯一入口 | 组件检查与人工评审 |
| 重放 | 登录成功回调重复执行账户动作 | 单槽 PendingIntent + generation + 单次消费 | 重复回调测试 |
| 信息泄露 | 日志打印 Cookie/URL 查询参数 | 字段白名单日志与脱敏 | 日志扫描测试 |
| 拒绝服务 | WebView/Steam 不可用阻断应用 | 游客始终可用，超时可取消 | 离线 smoke 测试 |
| 混淆状态 | 网络超时被判定会话失效 | 仅明确认证拒绝触发 Expired | 错误分类测试 |
| 本地篡改 | 设置值伪造 auto-login | 设置只接受 ask/guest，无法表达认证 | 篡改设置测试 |

## 4. 新鲜会话准备

`prepareFreshLoginSession()` 的顺序：

1. 初始化 WebView2 环境但不导航；
2. 获取 CookieManager；
3. 删除全部 Cookie，等待完成回调；
4. 将内存 Cookie jar 置空；
5. 仅在两者成功后导航到固定官方 HTTPS 登录 URL；
6. 进程内后续官方页面复用当前会话；注销后恢复“未准备”状态。

正常退出时调用现有 `clearSession()` 作为纵深防御。异常崩溃无法保证退出清理，因此“下次首次导航前清理”是主控制。

## 5. 导航与内容控制

沿用 CR-003 白名单并采用精确主机或受控子域匹配，禁止字符串后缀误判；仅允许 HTTPS。外部非白名单链接交给系统浏览器前需要用户确认，登录弹窗、新窗口请求同样经过策略。

页面标题、显示名和错误正文按不可信文本处理：不解释 HTML，不进入富文本模板，不写日志。应用自身欢迎页不加载远程脚本、图片或广告。

## 6. 会话失效与注销

- 只有明确的 Steam 认证拒绝映射为 `SessionRejected`；
- 转为 `Expired` 后立即停止/取消私有刷新，公开市场与本地功能继续；
- 注销幂等：清运行时快照、内存 Cookie、WebView Cookie、待执行意图；
- 清 Cookie 失败时 UI 显示“本地会话清理未完成”，阻止再次登录并提供安全重试；
- 注销不删除非敏感关注列表和市场缓存。

## 7. 隐私与日志

允许：状态名、错误码、耗时、WebView 能力、请求代次。

禁止：`steamLoginSecure`、`sessionid`、其他 Cookie 值，密码/验证码，完整 SteamID，WebView 页面正文，含查询参数的 URL。

调试构建也不得例外。SteamID 若诊断必需，仅输出末 4 位和不可逆散列前缀。

## 8. 安全验收清单

- [ ] 应用 UI 无用户名、密码、验证码输入控件；
- [ ] 启动与重启后状态不可能直接为 Authenticated；
- [ ] 预置 WebView Cookie 时，首次登录前被清理；
- [ ] 清理失败阻断导航但游客可用；
- [ ] 所有私有命令服务端入口都有权限门；
- [ ] 恶意/非 HTTPS 导航被拦截；
- [ ] 登录取消、重复回调、注销竞态不会重放动作；
- [ ] 日志扫描未发现 Cookie、凭据和完整 SteamID；
- [ ] smoke 模式不创建登录 WebView、不触发网络认证。

## 9. 剩余风险

Steam 官方页面与 WebView2 运行时属于外部依赖，页面变更或运行时缺失可能影响登录。通过能力检测、稳定错误状态、游客降级和 G3 集成测试降低影响；不通过放宽白名单或持久化 Cookie 规避。
