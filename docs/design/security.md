# 安全设计

> 安全工程师交付物（阶段 2）。本地单机桌面应用，信任边界以"本机用户 ↔ 外部网络数据源"为主。

## 1. 威胁建模（STRIDE）

| 威胁 | 场景 | 等级 | 缓解措施 |
| --- | --- | --- | --- |
| Spoofing 伪装 | 中间人伪造 Steam 响应 | 中 | 仅 HTTPS + 校验证书；域名白名单（steamcommunity.com / steamcdn-a.akamaihd.net） |
| Tampering 篡改 | 本地数据库/配置文件被篡改 | 中 | 本地单用户信任模型；不校验文件完整性（v1 接受）；日志只读定位问题 |
| Repudiation 抵赖 | 提醒触发/数据来源无审计 | 低 | 关键操作（提醒创建/触发、导入）记日志 |
| Information Disclosure 信息泄露 | 日志含敏感参数；抓包泄露比价 URL | 中 | 日志脱敏（不记录完整 market_hash_name 的查询串、不含 cookie）；比价仅取公开价格字段 |
| Denial of Service 拒绝服务 | Steam 限流导致被 ban；大响应拖垮 UI | 中 | 请求限速（默认 ≥1.5s/请求）+ 并发上限 1；响应体大小上限（默认 10MB）；解析失败丢弃不崩溃 |
| Elevation of Privilege 提权 | 解析第三方/网络数据导致代码执行 | 中 | 不加载第三方二进制；不 eval/不加载远程脚本；富文本一律禁用（Qt 富文本按纯文本处理）；仅解析 JSON 标量字段 |

## 2. 安全设计要点

- **传输**：QNetworkAccessManager 默认 TLS 1.2+，校验证书；不使用明文 HTTP；
- **输入校验**：搜索词长度/字符限制（≤128 字符）；`market_hash_name` 仅作 URL 路径编码与参数绑定，禁止拼 SQL；
- **注入防护**：全部 SQL 参数化（§数据库设计 5）；无 XSS 面（不渲染 HTML）；
- **密钥管理**：不保存 Steam 账号凭据；未来若需 API Key 存 Windows 凭据存储（DPAPI）；
- **本地数据**：数据库仅存公开市场数据与用户自录数据；设置项不含敏感值；
- **日志与审计**：分模块日志；错误信息不暴露堆栈给用户（日志可含堆栈）；记录提醒触发、CSV 导入等关键事件；
- **错误脱敏**：用户界面只显示统一错误码与可读文案，不显示原始 URL/响应片段。

## 3. 合规边界

- 仅调用 Steam 公开页面/接口，遵守 Steam 用户协议；不绕过限流、验证码或登录墙；
- 第三方平台（BUFF/C5/悠悠有品）接口非公开：不编写自动登录、验证码识别或高频率抓取逻辑；接入前由用户对合规风险签收（关联风险 R-002/R-006）；
- 数据仅用于个人查看，不对外分发。

## 4. 安全测试要点（供阶段 4 执行）

- 参数化 SQL 抽查（含引号/通配符用例）；
- 畸形 JSON/超长响应输入不崩溃；
- HTTPS 证书校验启用验证；
- 日志脱敏检查（无查询串/无 cookie）；
- 设置项非法值（负刷新间隔、超长文本）校验；
- 依赖漏洞扫描（vcpkg/包清单核对 CVE）。

# v2 变更（CR-001）

## 5. v2 威胁与缓解补充

| 威胁 | 场景 | 等级 | 缓解 |
| --- | --- | --- | --- |
| 信息泄露 | 盘口接口返回内容含地域/语言参数 | 低 | 仅本地展示，不写日志全文；参数固定 country=CN、language=schinese |
| DoS | itemordershistogram 高频请求触发限流/封禁 | 中 | 复用全局限速器（≥1.5s/请求），盘口仅详情页按需加载 |
| 数据完整性 | 规则库/费率配置被篡改 | 低 | 规则库内嵌只读资源；费率存 settings 可由用户自行校准 |
| 误导向 | 费用计算与实际 Steam 结算不一致 | 中 | 费率默认值与 Steam 官方一致（CS2 5%+10%），页面注明"以 Steam 实际结算为准" |

## 6. v2 合规

- 规则库仅作知识展示，不提供绕过平台规则的操作引导；
- 盘口数据仅个人查看，不对外分发。

# v3 变更（CR-002）

## 7. 凭据与会话安全

- **凭据**：密码仅存在于内存用于登录请求；Cookie 用 Windows DPAPI（CryptProtectData）加密后落盘，密钥由系统管理；
- **会话**：不与 UI 层共享明文 Cookie；日志不记录 Cookie/验证码；会话失效自动登出提示；
- **传输**：仅 HTTPS；Steam Guard 验证码只在内存中用于一次登录请求；
- **风控**：引擎层强制单日限额、冷却、去重；提供紧急停止；下单前校验钱包余额与幂等键。

## 8. v3 合规声明

- Steam 自动化交易可能违反平台订阅协议自动化条款，本功能默认人工确认、内置限额与提示，由用户自行承担账户风险；
- 不实现绕过 Steam Guard、验证码识别、并发多开等规避风控的行为。

## 9. v3 安全测试要点

- DPAPI 密文不可还原为明文（抽查数据库字段）；
- 登录失败/验证码错误不泄露内部信息；日志无凭据；
- 会话过期、余额不足、重复下单等边界用例。
