# ADR-002：SQLite 本地存储与可插拔数据源

- 状态：已接受（随 G1+G2 门禁批准生效）
- 日期：2026-08-01 / 阶段 2
- 决策者：系统架构师 + 数据库工程师

## 背景

需要持久化行情快照、历史走势、自选、提醒、持仓与第三方比价数据；同时第三方平台（BUFF/C5/悠悠有品）接口非公开，接入方式存在不确定性。

## 备选方案

1. **A：SQLite 单文件数据库**；
2. **B：JSON/CSV 文件存储**；
3. **C：客户端-服务器数据库（PostgreSQL 等）**。

## 结论

选择 **A（SQLite）**；比价数据源采用 **可插拔 `IPriceSource` 适配器**（内置 Steam 源 + CSV 导入兜底，平台源接入前做合规评估）。

## 理由

- SQLite 零部署、事务与索引完备，适合本地高频写入的行情快照；
- 文件型存储无法支撑按时间范围查询与去重约束；
- 第三方平台接口非公开且合规风险高（见 R-002/R-006），适配器隔离使未来接入或移除不影响核心架构。

## 影响

- 数据目录位于 `%APPDATA%/SteamMarketTerminal/`，需设计备份策略；
- 平台源接入属于变更控制范围，需用户对合规风险签收后再实施。
