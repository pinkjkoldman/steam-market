# 安全测试报告

> 依据 security.md 第 4 节测试要点执行（本地桌面应用，无外部攻击面）。

## 1. 检查结果

| 检查项 | 结果 | 说明 |
| --- | --- | --- |
| SQL 参数化 | 通过 | 全部 QSqlQuery::prepare 参数绑定，无字符串拼接 |
| 畸形输入不崩溃 | 通过 | 搜索空串/超长串校验；CSV 非法行跳过；JSON 解析失败返回错误不崩溃 |
| HTTPS | 通过 | 仅 https://steamcommunity.com，默认证书校验 |
| 日志脱敏 | 通过 | 不记录 cookie/会话；market_hash_name 仅作为业务字段，无敏感数据 |
| 设置校验 | 通过 | 刷新间隔 1–1440、请求间隔 500–10000ms 边界校验 |
| 依赖漏洞 | 低风险 | 仅使用 Qt 6.11 官方组件，无第三方运行时依赖 |
| 密钥 | 不适用 | 应用不保存账号密码/API Key |

## 2. 结论

- 无高危漏洞；本地单机应用攻击面小；
- 合规红线（不写反爬/不绕过登录验证码）在代码中未实现相关逻辑 ✓。
