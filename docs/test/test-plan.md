# 测试计划

> 阶段 4 测试验证（与阶段 3 合并门禁）。范围：核心服务与数据层单元测试 + 应用冒烟自测。

## 1. 测试范围与策略

| 层级 | 对象 | 方式 |
| --- | --- | --- |
| 单元测试 | 迁移/仓储/提醒/持仓/CSV 导入/设置 | Qt Test（临时 SQLite 库，无外部依赖） |
| 冒烟测试 | 应用整体 | `--smoke-test`：临时库 + 演示数据 → 核心自检 → UI 截图 |
| 手工验证 | 真实 Steam 接口、托盘通知 | 需要联网/托盘环境，交付后用户自测 |

## 2. 环境

- Windows 11，Qt 6.11.0（MinGW 13.2），构建 `scripts/build.ps1`；
- 单元测试不依赖网络（全部本地临时库）。

## 3. 外部依赖 Mock 策略

- Steam 接口不在单元测试中调用（网络层由冒烟/手工验证覆盖）；
- 数据库用 `QTemporaryDir` 每用例独立临时文件，保证可重复。

## 4. 准出标准（G4）

- Must 用例 100% 执行、通过率 ≥ 95%；
- 无未关闭高危缺陷；
- 冒烟退出码 0 且截图成功生成。
